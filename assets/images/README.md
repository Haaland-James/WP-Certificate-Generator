# Certificate Template

This directory should contain your certificate template image.

## Required File

Place your certificate template image here as:
- `certificate-template.png`

## Template Requirements

- Format: PNG
- Recommended size: 1024x726 pixels (or similar landscape format)
- The attendee name will be overlaid at approximately Y=320px, centered horizontally
- Use a clear background area where the name will appear

## Custom Font (Optional)

For better text rendering, you can add a custom TTF font:
- Place it in `assets/fonts/Montserrat-SemiBold.ttf` or `assets/fonts/certificate-font.ttf`

If no custom font is provided, the plugin will use PHP GD's built-in font.
