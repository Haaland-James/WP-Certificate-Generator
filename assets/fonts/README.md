# Custom Fonts

This directory is for custom TrueType fonts used in certificate generation.

## Supported Font Names

The plugin will look for fonts in this order:
1. `certificate-font.ttf` (custom name)
2. `Montserrat-SemiBold.ttf` (recommended)

## Recommended Font

Download Montserrat from Google Fonts: https://fonts.google.com/specimen/Montserrat

Use the SemiBold (600) weight for best results.
